# TBC 2.4.3 API catalog

These files target client build `2.4.3.8606`. Every record carries availability separately from emulator status. `SupportedInTBC` requires direct 2.4.3 FrameXML evidence or a reliable introduction annotation at/before 2.4.3 with no earlier removal. `NotInTBC` requires a later introduction/removal annotation. Anything else is `Uncertain`.

Historical references can be incomplete or span multiple expansions. Evidence text explains why each classification was made. Presence in modern documentation alone is never evidence of TBC availability.

Catalog schema version 1.0 is represented by `ApiCatalogEntry` in the Core project and validated by automated tests.
